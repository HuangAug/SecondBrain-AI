# 合规清单

## 上线前必做

### 1. ICP 备案

- [ ] 注册域名并完成 ICP 备案（约 2–4 周）
- [ ] API 服务使用已备案域名
- [ ] App 内展示备案号

### 2. 隐私与协议

- [ ] 发布《隐私政策》，说明收集的手机号、学习数据、AI 处理方式
- [ ] 发布《用户协议》与《AI 生成内容免责声明》
- [ ] 首次启动展示协议同意弹窗
- [ ] App Store / 各安卓商店填写隐私清单

### 3. 个人信息保护

- [ ] 手机号加密存储
- [ ] 提供账号注销与数据删除入口
- [ ] 用户文档仅本人可访问（已实现 user_id 隔离）
- [ ] AI 对话数据保留策略文档化（建议 90 天）

### 4. 内容安全

- [ ] 接入腾讯云/阿里云文本内容审核 API（生产环境）
- [ ] 提供内容举报入口
- [ ] 基础敏感词过滤（已实现 `content_filter.py`）

### 5. 应用商店

- [ ] Apple Developer 账号（¥688/年）
- [ ] App Store 年龄分级与 AI 功能说明
- [ ] 华为、小米、应用宝等国内安卓商店资质

### 6. 监控

- [ ] Sentry 崩溃监控（配置 `SENTRY_DSN`）
- [ ] 基础埋点：DAU、对话数、文档上传数

## 成本参考（MVP 月）

| 项目 | 预估 |
|------|------|
| 腾讯云轻量服务器 | ¥60 |
| 对象存储 COS | ¥10 |

## 数据出境

若使用国内服务器 + 国内 AI API，用户数据不出境，合规风险较低。
